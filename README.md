# Attendance Management System - QA Project

## Overview

A web-based Attendance Management System created as a System Under Test for practicing software quality assurance and test automation.

The project covers UI testing, API testing, database validation, authorization, negative testing, and automated regression testing.

## Technologies

- HTML
- JavaScript
- Node.js
- Express.js
- SQLite
- Playwright
- Postman
- Git
- GitHub

## QA Testing Covered

- Login validation
- Teacher attendance management
- Student authorization
- Invalid input validation
- Attendance database verification
- API response validation
- UI automation
- API automation
- Negative testing
- Failure investigation and retesting
